# Collective Intelligence

Field notes on building on-policy team RL for LLM agents: what an untrained team does with teammates, why the solo control comes first, the agentic arm that didn't learn, the bugs that silently corrupt RL, and how to credit one decision inside a running team.

**→ Read the essay: [macoredroid.github.io/collective-intelligence](https://macoredroid.github.io/collective-intelligence/)**

Part 1 covers the groundwork; no team has been trained yet. The page is a single static file in [`docs/index.html`](docs/index.html), served by GitHub Pages from `/docs`.
